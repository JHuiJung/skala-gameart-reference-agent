# 색상 사용 규정

> ⚠️ MOCK 문서: 구조 테스트용 가상 규정입니다. 수치는 예시이므로 실제 값으로 교체하세요.

- 문서 상태: 시행 중
- 담당: 아트 파이프라인팀
- 적용 범위: 모든 3D 모델, 2D 텍스처, 이펙트

## 1. 팔레트 제한
- **오브젝트 하나에 사용하는 주요 색상은 최대 5색**을 넘지 않는다. (중간 톤 변화는 별도 색으로 세지 않는다.)
- 몬스터는 3색 구성을 권장, 보스는 최대 5색까지 허용한다.
- 한 화면(씬)에 동시에 등장하는 고채도 색은 2종 이하로 제한한다.

## 2. 채도 및 명도
- 기본 채도 상한: 60% (HSV 기준). 초과하려면 아트 디렉터 승인 필요.
- 고채도 색은 주요 오브젝트와 상호작용 요소에만 사용한다.
- 순수 검정(#000000)과 순수 흰색(#FFFFFF)은 텍스처에 직접 사용하지 않는다. (명도 범위 권장: 5%~95%)

## 3. 색상 일관성
- 프로젝트 공통 팔레트 파일(`project_palette.ase`)의 색을 우선 사용한다.
- 팔레트 밖의 색을 쓸 때는 사유를 지시서에 기록한다.
- 같은 종족/세력은 동일 색상 계열을 공유한다.

## 4. 접근성
- 적과 아군, 위험 요소는 색상뿐 아니라 형태나 패턴으로도 구분 가능해야 한다.
- 주요 UI와 배경 사이의 명도 대비는 최소 4.5:1을 확보한다.
