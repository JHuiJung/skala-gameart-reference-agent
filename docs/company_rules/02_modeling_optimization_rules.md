# 3D 모델링 최적화 규정

> ⚠️ MOCK 문서: 구조 테스트용 가상 규정입니다. 수치는 예시이므로 타겟 플랫폼과 엔진 기준으로 교체하세요.

- 문서 상태: 시행 중
- 담당: 테크니컬 아트팀
- 타겟 플랫폼(가정): PC 중사양 / 콘솔

## 1. 폴리곤 예산 (삼각형 기준)
| 분류 | LOD0 상한 | 비고 |
|---|---|---|
| 일반 몬스터 | 25,000 | |
| 정예 몬스터 | 40,000 | |
| 보스 | 100,000 | |
| 플레이어 캐릭터 | 60,000 | |
| 건물(중형) | 15,000 | 내부 포함 시 협의 |
| 소품(소형) | 2,000 | 반복 배치 오브젝트 |
| 식생 카드 | 500 | |

## 2. LOD
- 모든 몬스터와 건물은 최소 **LOD 3단계** 제공
- 단계별 폴리곤 비율 권장: LOD1 50%, LOD2 25%, LOD3 10%
- 소품은 LOD2까지 허용, 원거리 비표시 거리 지정

## 3. 머티리얼 및 드로우콜
- 오브젝트당 머티리얼 슬롯 **최대 3개**
- 같은 종류의 소품은 텍스처 아틀라스로 통합해 배칭 가능하게 제작
- 알파 블렌딩(반투명) 머티리얼은 오버드로 방지를 위해 필요한 곳에만 사용 (알파 테스트 우선)

## 4. 형태 및 메시 품질
- 불필요한 내부 면, 보이지 않는 면 제거
- N-gon 금지, 최종 삼각형화 상태에서 노멀 오류 없을 것
- 대칭 오브젝트는 UV 미러링으로 텍스처 용량 절약 (단, 눈에 띄는 비대칭 디테일은 예외)
- 디테일은 폴리곤이 아닌 노멀맵으로 표현
- 이끼, 덩굴 같은 가닥형 요소는 메시 카드(평면)로 표현

## 5. 스켈레톤 및 애니메이션
- 일반 몬스터 본 수 최대 80, 보스 최대 150
- 리깅 시 본당 영향받는 버텍스 가중치는 최대 4개
