# 텍스처 및 리소스 규정

> ⚠️ MOCK 문서: 구조 테스트용 가상 규정입니다. 수치는 예시이므로 실제 값으로 교체하세요.

- 문서 상태: 시행 중
- 담당: 테크니컬 아트팀

## 1. 해상도 기준
| 분류 | 최대 해상도 |
|---|---|
| 보스 / 플레이어 | 4096 x 4096 |
| 일반·정예 몬스터 | 2048 x 2048 |
| 건물 | 2048 x 2048 |
| 소품 | 1024 x 1024 |
| 식생·이펙트 | 512 x 512 |

- 해상도는 반드시 **2의 거듭제곱**을 사용한다.
- 화면에서 차지하는 비중이 작은 오브젝트에는 높은 해상도를 쓰지 않는다.

## 2. 텍스처 구성 (PBR)
- 기본 세트: Base Color / Normal / ORM(AO, Roughness, Metallic를 채널 패킹)
- 단순 오브젝트는 ORM 대신 채널 패킹 통합 맵 하나로 대체 가능
- Emissive는 발광체(등불, 핵 등)에만 사용

## 3. 압축 및 포맷
- 작업 원본: PSD/TGA (16bit 허용), 버전 관리 대상
- 엔진 반입: PNG 또는 TGA, 엔진 내 압축은 BC7(Color) / BC5(Normal)
- 알파가 필요 없으면 알파 채널 제거

## 4. 용량 제한
- 일반 몬스터 한 개체의 텍스처 총합 12MB 이하 (압축 후)
- 보스 40MB 이하
- 한 씬의 텍스처 메모리 총량 1.5GB 이하

## 5. 밉맵 및 스트리밍
- 모든 텍스처에 밉맵 생성
- 큰 환경 텍스처는 스트리밍 가능 설정

## 6. UV
- UV 섬 사이 패딩 최소 8px (2048 기준)
- 텍스처 공간 사용률 80% 이상 권장
- 타일링 텍스처와 유니크 텍스처를 혼용할 때 텍셀 밀도를 통일
