# 파일 네이밍 및 납품 규정

> ⚠️ MOCK 문서: 구조 테스트용 가상 규정입니다. 실제 사내 규칙으로 교체하세요.

- 문서 상태: 시행 중
- 담당: 아트 파이프라인팀

## 1. 네이밍 규칙
- 영문 소문자와 언더스코어(`_`) 사용, 공백과 한글 금지
- 형식: `{분류}_{이름}_{변형}_{번호}`
  - 예: `mon_moss_wolf_body_01`, `env_wooden_house_roof_02`
- 접두어: `mon_`(몬스터), `env_`(환경), `prop_`(소품), `chr_`(캐릭터), `fx_`(이펙트)
- 텍스처 접미어: `_bc`(Base Color), `_n`(Normal), `_orm`, `_e`(Emissive)

## 2. 폴더 구조
```text
{분류}/{이름}/
├── source/    (원본 PSD, 블렌드/마야 파일)
├── mesh/
├── textures/
└── anim/
```

## 3. 단위 및 좌표
- 단위: 1 유닛 = 1cm
- 업축: Z-up, 앞방향 +X (엔진 기준에 맞춰 내보내기)
- 피벗: 오브젝트 바닥 중심
- 스케일은 반드시 (1, 1, 1)로 프리즈하여 내보낸다.

## 4. 납품 체크리스트
- [ ] 폴리곤 예산 이내
- [ ] LOD 3단계 포함
- [ ] 머티리얼 슬롯 3개 이하
- [ ] 텍스처 해상도와 용량 기준 충족
- [ ] 색상 5색 이하
- [ ] 네이밍 규칙 준수
- [ ] 스케일 프리즈 완료
- [ ] 기획서와 일치 확인 (크기, 색상, 금지 요소)

## 5. 외부 레퍼런스 및 저작권
- 레퍼런스 이미지는 출처 URL과 라이선스 상태를 반드시 기록한다.
- 상업적 이용 여부가 불명확한 이미지는 **참고용으로만** 사용하고, 직접 트레이싱·복제하지 않는다.
- 생성형 AI 이미지는 아이디어 참고용으로만 사용하며 최종 산출물에 직접 포함하지 않는다.
