# 몬스터 기획: 안개거인 (Mist Giant)

> ⚠️ MOCK 문서: 구조 테스트용 가상 기획서입니다.

- 문서 상태: 확정
- 담당: 몬스터 기획팀
- 최종 수정: 2026-09-25

## 1. 기본 정보
| 항목 | 내용 |
|---|---|
| 종족 | 안개 거신족 (구 왕국 병사의 변이체) |
| 등급 | 보스 |
| 크기 | 신장 약 6.5m |
| 서식지 | 숲 심층부, 옛 왕궁 터 |
| 등장 조건 | 안개 농도 최대 |

## 2. 외형 특징
- 녹슨 갑옷 조각이 살에 박힌 거대한 인간형 실루엣
- 얼굴은 부서진 투구가 융합되어 눈구멍만 남아 있다
- 몸 아래쪽은 안개와 섞여 윤곽이 흐릿하다
- 한쪽 팔이 반대쪽보다 1.5배 길고, 부러진 대검을 끌고 다닌다

## 3. 색상
탁한 청회색(몸), 녹슨 갈색(갑옷), 탁한 청록(눈과 안개 이펙트) **3색 구성**.

## 4. 행동 및 전투 패턴
- 느린 걸음, 큰 범위 내려치기
- 2페이즈에서 주변 안개를 흡수해 시야를 제한
- 대검을 땅에 꽂아 충격파 발생

## 5. 연출 포인트
- 등장 시 플레이어 시야에는 실루엣만 보이다가, 가까워질수록 디테일이 드러난다
- 거대함을 표현하기 위해 주변에 마을 건물 크기와 비교되는 구도를 사용

## 6. 디자인 주의점
- 근육질 영웅형 체형이 아닌, 마르고 굽은 체형으로 불안감을 준다
- 갑옷은 새것처럼 반짝이지 않고 부식 질감을 유지한다
