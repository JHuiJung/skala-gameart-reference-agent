# 몬스터 기획: 가시덩굴 정령 (Thorn Wisp)

> ⚠️ MOCK 문서: 구조 테스트용 가상 기획서입니다.

- 문서 상태: 확정
- 담당: 몬스터 기획팀
- 최종 수정: 2026-09-28

## 1. 기본 정보
| 항목 | 내용 |
|---|---|
| 종족 | 식물 정령 |
| 등급 | 정예 몬스터 |
| 크기 | 높이 약 2.4m (평소 웅크린 상태 1.2m) |
| 서식지 | 폐허 주변, 습지 |
| 특징 | 움직이지 않을 때는 덤불로 위장 |

## 2. 외형 특징
- 가시 돋친 덩굴이 사람 형상으로 뭉쳐진 모습
- 가슴 중앙에 희미하게 빛나는 씨앗 핵(약점)
- 팔은 채찍처럼 길게 늘어나는 덩굴

## 3. 색상
암녹색(덩굴), 흙갈색(뿌리), 탁한 청록(핵) **3색 구성**.

## 4. 행동 및 전투 패턴
- 위장 상태에서 기습, 이후 중거리 채찍 공격
- 핵이 노출되는 순간에만 큰 피해를 줄 수 있음
- 불 속성에 취약, 불이 붙으면 광폭화

## 5. 디자인 주의점
- 꽃이나 열매 등 화사한 요소 금지 (귀여워 보이지 않게)
- 덩굴 가닥 수가 많아 보이되 실제 메시는 단순하게 (최적화 규정 참고)
